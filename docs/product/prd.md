# 别吃灰 Web PRD

日期：2026-06-10

## 1. 产品概述

别吃灰 Web 是一个本地个人知识库管理应用。第一版面向浏览器使用，后续同一套 Web UI 可被桌面套壳应用复用。

产品核心是把用户收藏的链接稳定导入本地，自动生成知识卡片，再通过文件夹、标签、日历、搜索和 AI 问答帮助用户整理、回看和复用资料。

第一版采用“轻量收藏整理器”方向，不做登录、多用户、云同步和批量导入。

## 2. 用户目标

- 快速导入一篇网页文章。
- 导入时把文章放进明确的文件夹。
- 在 Home 看板看到知识库总体状态和最近导入任务。
- 在知识库中按文件夹、标签和时间浏览卡片。
- 查看、编辑和维护单张知识卡片。
- 按日期回顾当天导入内容，并生成日报。
- 用模糊记忆找回收藏过的卡片，并基于卡片问答。
- 浏览 AI 热点推荐，预览后单篇导入。

## 3. 范围

### 3.1 第一版包含

- 单链接导入。
- 文件夹选择和新建。
- AI 自动生成摘要和标签。
- Home 数据看板。
- 知识活动热力图。
- 最近导入任务状态。
- 知识库全部收藏和文件夹视图。
- 卡片网格视图和紧凑列表视图。
- 卡片详情、编辑和维护操作。
- 回收站、恢复和永久删除。
- 日历日期详情。
- 日历日报生成。
- 模糊记忆搜索。
- 选卡问答。
- AI 热点推荐、预览和单篇导入。

### 3.2 第一版不包含

- 登录、多用户、权限系统。
- 云同步。
- 批量链接导入。
- PDF、Markdown、本地文件或浏览器收藏夹导入。
- 无限层级文件夹。
- 日报保存为知识库卡片。
- 复杂笔记编辑器或 Markdown 备注。
- 评测工作台产品化。

## 4. 信息架构

左侧主导航：

- `+ 导入`
- `Home`
- `知识库`
- `日历`
- `搜索`
- `AI 热点推荐`
- `设置 / 备份 / 导出`

`知识库` 展开后显示：

- 全部收藏
- 用户文件夹
- 未分类
- 回收站
- 新建文件夹

回收站只在知识库内部出现，不作为主导航项。

## 5. 核心页面需求

### 5.1 Home

Home 是数据看板。

顶部统计：

- 累计文章数。
- 累计文字数。
- 文件夹数。
- 本周导入数。

知识活动热力图：

- 每个方块代表一天。
- 方块颜色表示当天导入活跃度。
- 鼠标悬停显示当天导入文章数量和文字数量。
- 点击某天进入日历页，并定位到该日期详情。

最近导入：

- 展示最近导入任务。
- 状态包括 `导入中`、`导入成功`、`导入失败`。
- 导入中展示当前阶段或进度提示。
- 导入成功展示生成的卡片和文件夹。
- 导入失败展示失败原因，并支持重试。

AI 热点推荐摘要：

- 展示少量热点文章。
- 点击进入 AI 热点推荐页。
- 热点文章可预览后导入。

### 5.2 导入弹窗

触发入口：

- 用户点击左侧 `+ 导入`。
- 用户在 AI 热点推荐页点击某篇文章的导入操作。

字段：

- URL。
- 目标文件夹。
- 新建文件夹入口。

规则：

- 一次只能导入一个 URL。
- 未选择文件夹不能开始导入。
- 开始导入后创建导入任务。
- 弹窗可以关闭。
- 任务状态在 Home 最近导入中展示。
- 标签由 AI 自动生成，导入后可编辑。

### 5.3 知识库

默认进入“全部收藏”。

布局：

- 默认双栏：左侧主导航 + 右侧内容区。
- 点击卡片后变三栏：左侧主导航 + 中间卡片列表 + 右侧卡片详情。
- 用户可以关闭详情栏回到双栏。

列表能力：

- 网格视图。
- 紧凑列表视图。
- 按文件夹筛选。
- 按标签筛选。
- 按来源筛选。
- 按时间排序。
- 默认排除回收站内容。

文件夹规则：

- 文件夹为单层结构。
- 每张卡片有且只有一个文件夹。
- 系统提供“未分类”文件夹。
- 文件夹支持新建、重命名和删除。
- 删除文件夹时，文件夹内卡片移动到“未分类”。

### 5.4 卡片详情

展示字段：

- 标题。
- 来源链接。
- 来源站点。
- 文件夹。
- 标签。
- AI 摘要。
- 原文预览和完整原文。
- 纯文本备注。
- 创建时间和更新时间。
- 重要标记。
- 坏数据标记。

操作：

- 编辑标题。
- 编辑摘要。
- 编辑标签。
- 编辑备注。
- 移动到其他文件夹。
- 打开来源链接。
- 查看完整原文。
- 重新抓取原文。
- 重新生成摘要和标签。
- 标记或取消标记重要。
- 标记或取消标记坏数据。
- 移到回收站。

覆盖保护：

- 重新抓取和重新生成摘要/标签需要明确提示。
- 如果会覆盖用户手动编辑内容，需要二次确认。

### 5.5 回收站

删除采用两段式。

普通删除：

- 卡片进入回收站。
- 正常知识库列表、搜索、问答和日历默认排除回收站内容。

恢复：

- 恢复到原文件夹。
- 如果原文件夹不存在，则恢复到“未分类”。

永久删除：

- 删除知识卡片、原文条目、FTS 索引和向量索引关联数据。
- 永久删除不可恢复，需要二次确认。

### 5.6 日历和日报

日历页按日期展示导入的知识卡片。

入口：

- 左侧 `日历`。
- Home 知识活动热力图日期方块。

日期详情：

- 展示当天导入卡片列表。
- 展示当天文章数。
- 展示当天文字数。
- 支持打开卡片详情。

日报生成：

- 只在日历页生成。
- 不保存为知识库卡片。
- 内容包括当天导入文章列表、当天知识内容总结、主题、关键词和值得回看的卡片。

### 5.7 搜索和 AI 问答

搜索采用两段式流程。

第一段：模糊记忆检索。

- 用户输入自然语言描述。
- 系统改写查询并召回匹配卡片。
- 结果展示标题、摘要、来源、文件夹、标签和相关性信息。

第二段：选卡问答。

- 用户选择一张或多张卡片。
- 用户基于所选卡片提问。
- 系统基于所选卡片和原文生成回答。
- 回答展示引用来源，并允许跳回卡片详情。

搜索和问答默认不使用回收站内容。

### 5.8 AI 热点推荐

功能：

- 展示热点文章列表。
- 支持分类筛选，例如全部、AI 产品、技巧、精选。
- 点击文章打开预览。
- 预览展示标题、来源、发布时间、简介和原链接。
- 用户可以从预览中发起单篇导入。
- 导入复用统一导入弹窗，并必须选择文件夹。
- 已导入文章显示状态，避免重复导入。

第一版不做批量导入。

## 6. 数据和状态

### 6.1 导入任务状态

任务状态：

- `pending`
- `running`
- `succeeded`
- `failed`

任务阶段：

- `waiting`
- `fetching`
- `summarizing`
- `embedding`
- `saving`
- `done`
- `failed`

### 6.2 卡片状态

卡片支持：

- 文件夹归属。
- 多标签。
- 备注。
- 重要标记。
- 坏数据标记。
- 软删除状态。

### 6.3 系统文件夹

- 未分类：系统文件夹，不允许删除。
- 回收站：通过软删除状态实现，不作为普通文件夹。

## 7. 错误处理

导入失败必须展示：

- URL。
- 目标文件夹。
- 失败阶段。
- 失败原因。
- 重试入口。

常见错误：

- URL 无效。
- 抓取失败。
- 正文为空。
- 页面是占位页或登录页。
- 模型 API key 缺失。
- 模型调用失败。
- embedding 失败。
- 写库失败。

模型 API 不可用时，需要明确提示，不静默失败。

## 8. 验收标准

- 用户可以通过导入弹窗把单个链接导入指定文件夹。
- Home 能展示统计、知识活动热力图、最近导入状态和 AI 热点推荐摘要。
- 用户可以进入知识库查看全部收藏和文件夹内容。
- 用户点击卡片后能看到详情，并可以编辑标题、摘要、标签、备注和文件夹。
- 用户可以把卡片移入回收站、恢复或永久删除。
- 用户可以在日历页查看某天卡片，并生成当天日报。
- 用户可以用模糊记忆搜索卡片，选择卡片后提问并得到带引用回答。
- 用户可以在 AI 热点推荐页预览文章，并单篇导入。
- 评测工作台不出现在主应用导航中。
