# Windows 安装版说明

## 安装

当前 Windows 安装包输出路径：

- `src-tauri/target/release/bundle/nsis/别吃灰_0.1.0_x64-setup.exe`

双击安装包后，按安装器提示完成安装即可。

## 首次使用

安装完成后：

1. 打开“别吃灰”
2. 进入“设置”
3. 找到 `API 与模型配置`
4. 填写 `SILICONFLOW_API_KEY`
5. 保存配置

完成后，就可以开始使用导入、摘要、搜索和问答功能。

## 最小 API 配置

当前最推荐的最小配置是：

- `SILICONFLOW_API_KEY`

只填这一项时，应用会优先复用它来支持：

- 导入后的摘要生成
- 搜索相关能力
- 选卡问答
- 其他基础模型调用

如果你没有先配置它：

- 应用仍然可以打开
- 但导入、摘要、搜索和问答不会正常工作

## 适合普通使用者的理解方式

可以把这一步理解成：

- 安装应用
- 打开应用
- 填一个 API key
- 开始使用

当前版本不要求普通用户手动安装 Python，也不要求自己启动前后端服务。
