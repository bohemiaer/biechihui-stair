# 别吃灰

一个本地优先的个人知识库桌面应用。

把收藏的文章、网页和灵感资料真正整理起来，而不是丢进收藏夹后慢慢吃灰。

## 项目介绍

别吃灰面向长期积累资料、经常“记得看过但找不到”的个人用户。

它希望解决几个很常见的问题：

- 收藏了很多文章，但很少再回看。
- 资料分散在浏览器收藏夹、聊天记录和笔记工具里。
- 记得一个模糊概念，却想不起标题、来源或保存位置。
- 想把每天读到的内容沉淀下来，而不是只看一遍。

这个项目的目标不是做一个“大而全”的云笔记平台，而是做一个更轻、更安静、更适合个人长期使用的本地知识库。

## 核心功能

- 单链接导入：输入一篇网页链接，导入到指定文件夹。
- 自动生成卡片：抓取正文后生成摘要、标签和可检索内容。
- 知识库整理：按文件夹、标签和时间浏览收藏内容。
- 卡片详情维护：查看原文、编辑标题、摘要、标签和备注。
- 日历回顾：按日期查看当天导入内容，并生成日报。
- 模糊记忆搜索：用自然语言找回“记得看过但想不起名字”的资料。
- 选卡问答：基于选中的知识卡片进行问答，并返回引用来源。
- AI 热点推荐：浏览推荐文章，预览后单篇导入。

## 桌面安装包

Windows 安装包通过 GitHub Release 分发，普通用户可以直接下载最新版本安装。

最新安装包下载：

- [GitHub Releases](https://github.com/bohemiaer/biechihui-stair/releases)

安装后：

1. 打开应用
2. 进入“设置”
3. 填写 `SILICONFLOW_API_KEY`
4. 返回首页开始导入、搜索和问答

如果没有先配置 API key，应用仍然可以打开，但导入、摘要、搜索和问答这些能力不会正常工作。

## 使用方式

一个典型流程大致是这样：

1. 导入一篇网页文章到指定文件夹
2. 等待系统抓取正文并生成知识卡片
3. 在知识库中浏览、编辑和整理卡片
4. 通过搜索或问答重新找回过去保存的内容
5. 在日历页回看每天积累了什么

## 常见问题

### 我应该怎么最快体验这个项目？

从 [GitHub Releases](https://github.com/bohemiaer/biechihui-stair/releases) 下载最新 Windows 安装包，安装后打开应用，再去设置页填写 `SILICONFLOW_API_KEY`。

### 为什么只强调 `SILICONFLOW_API_KEY`？

因为这是当前最小可用配置。先填它，就可以开始使用导入、摘要、搜索和问答。其他模型配置只在你需要更细分的服务时再补。

### 这是一个完全离线的应用吗？

不是。它是本地优先应用，但导入后的摘要、搜索问答等 AI 能力仍然依赖你配置的模型 API。
